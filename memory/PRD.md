# Taxi WebToApp - PRD

## Original Problem Statement
WebToApp платформа для такси с интеграцией OneSignal для push-уведомлений. Мобильная версия + адаптив для ПК.

## Architecture
- **Backend**: FastAPI + MongoDB + WebSocket для real-time
- **Frontend**: React с Tailwind CSS + Shadcn UI
- **Auth**: JWT токены с сохранением сессии
- **Интеграции**: SMS.ru, OneSignal, Yandex/Google/2GIS Maps, SMTP (MOCK для MVP)

## User Personas
1. **Пассажир (Customer)** - заказывает такси по адресу
2. **Водитель (Driver)** - принимает и выполняет заказы
3. **Администратор** - управляет системой, настройками, пользователями

## Core Requirements (Static)
- Регистрация по телефону с SMS-кодом
- Выбор роли при входе (без переключения в сессии)
- Ручная активация водителей админом
- Система баланса поездок для водителей
- Проблемные заявки с уведомлением админу
- Настраиваемые тексты правил и условий
