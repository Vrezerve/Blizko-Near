# PRD — Такси "Рядом" (WebToApp)

## Описание
Сервис такси/райдшеринга с ролями Заказчик, Водитель, Администратор.

## Стек
React + TailwindCSS + Shadcn, FastAPI, MongoDB, JWT + PIN + OTP, WebSockets, Yandex Maps, SMS.ru

## Реализовано

### Авторизация
- [x] OTP верификация (реальные SMS через SMS.ru + fallback на push)
- [x] PIN-код для быстрого входа
- [x] Device ID привязка + блокировка (лимит 5 регистраций)
- [x] Тестовый режим (вкл/выкл в админке)

### Карты
- [x] Интеграция Яндекс Карт (реальная карта при наличии API-ключа)
- [x] Отображение водителя на карте в реальном времени
- [x] Fallback на мок-карту при отсутствии ключа

### SMS
- [x] Интеграция SMS.ru (реальная отправка SMS)
- [x] Fallback на push/лог если ключ не задан

### Админ-панель
- [x] Системные логи (уровни: error/warning/info/debug, фильтр, очистка, вкл/выкл)
- [x] Модули с ZIP-архивом + удаление
- [x] Тестовый режим
- [x] Настройки API-ключей

### Деплой
- [x] install.sh v2.0 (1 вопрос — домен)
- [x] install.php (визуальный)
- [x] Гайд Timeweb
