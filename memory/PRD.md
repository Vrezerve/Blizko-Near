# PRD — Такси "Рядом" (WebToApp)

## Описание
Сервис такси/райдшеринга с ролями Заказчик, Водитель, Администратор. Мобильно-адаптивное веб-приложение.

## Стек
- Frontend: React + TailwindCSS + Shadcn UI
- Backend: FastAPI (Python)
- Database: MongoDB
- Auth: JWT + PIN-код + OTP (Push/SMS)
- Real-time: WebSockets

## Реализовано

### Авторизация
- [x] Выбор роли (Заказчик / Исполнитель / Админ)
- [x] OTP верификация (Push-уведомления, MOCKED)
- [x] PIN-код для быстрого входа (4 цифры, bcrypt-хэш)
