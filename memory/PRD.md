# PRD — Такси "Рядом" (WebToApp)

## Описание
Сервис такси/райдшеринга с ролями Заказчик, Водитель, Администратор.

## Стек
React + TailwindCSS + Shadcn, FastAPI, MongoDB, JWT + PIN + OTP, WebSockets

## Реализовано

### Авторизация
- [x] OTP верификация (тестовый код 1234 при включённом тестовом режиме)
- [x] PIN-код для быстрого входа (4 цифры)
- [x] Сброс PIN через SMS/Push
- [x] Device ID привязка + блокировка устройств
- [x] JWT токены (30 дней)
- [x] Тестовый режим (вкл/выкл в админке)

### Брендинг
- [x] Редактируемое название приложения
- [x] Загрузка иконки (PNG/JPEG/WebP/SVG)
- [x] Удалён бейдж "Made with Emergent"

### Заказы
- [x] Создание, принятие, завершение, отмена
- [x] Проблемные заказы
- [x] История заказов

### Водители
- [x] Регистрация + активация админом
- [x] Мгновенный выход на линию
- [x] Real-time обновление местоположения

### Админ-панель
- [x] Дашборд, карта, пользователи, заказы, логи
- [x] Модули: создание + ZIP-архив + вкл/выкл + удаление
- [x] Тестовый режим — переключатель в настройках
- [x] Настройки API, SMTP, карты, брендинг

### Деплой
