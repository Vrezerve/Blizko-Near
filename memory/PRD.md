# PRD — Такси "Рядом" (WebToApp)

## Описание
Сервис такси/райдшеринга с ролями Заказчик, Водитель, Администратор.

## Стек
React + TailwindCSS + Shadcn, FastAPI, MongoDB, JWT + PIN + OTP, WebSockets

## Реализовано

### Авторизация
- [x] OTP верификация (тестовый код 1234)
- [x] PIN-код для быстрого входа (4 цифры)
- [x] Сброс PIN через SMS/Push
- [x] Device ID привязка + блокировка устройств
- [x] JWT токены (30 дней)

### Брендинг
- [x] Редактируемое название приложения
- [x] Загрузка иконки (файл, PNG/JPEG/WebP/SVG)
- [x] Общий компонент AppLogo

### Заказы
- [x] Создание, принятие, завершение, отмена
- [x] Проблемные заказы
- [x] История заказов

### Водители
- [x] Регистрация + активация админом
- [x] Выход на линию (без блокировки по балансу)
- [x] Real-time обновление местоположения

### Админ-панель
- [x] Дашборд, карта, пользователи, заказы
- [x] Брендинг (загрузка иконки)
- [x] Заблокированные устройства
- [x] Обновления и модули (загрузка ZIP, управление модулями)
- [x] Настройки API, SMTP, логи

### Деплой
- [x] Подробный гайд Timeweb — терминал (/app/docs/timeweb_guide.md)
- [x] Подробный гайд Timeweb — ISPmanager 6 (12 шагов)
- [x] Автоинсталятор install.sh + инструкция по использованию (шаги А–Е)
- [x] **PHP Веб-Инсталятор install.php** — визуальный пошаговый установщик через браузер (7 шагов: проверка системы, установка зависимостей, настройка, сборка, nginx + SSL, финальная проверка)
